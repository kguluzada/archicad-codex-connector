Windows setup / v0.1.0

Connect in four steps.

Run the connector on the same Windows machine as your licensed Archicad installation. Internet access is needed to install Python dependencies.

Intended target: Windows 10/11, Archicad 25–30 and Python 3.12–3.14. Native Windows and Archicad acceptance has not yet been run. Begin with a saved, disposable PLN project.

01 / Prepare the host

Install the matching Tapir add-on

Download the Tapir 1.7.0 Windows asset for your Archicad major version: TapirAddOn_AC25_Win.apx through TapirAddOn_AC30_Win.apx.

In Archicad, open Options → Add-On Manager → Edit List of Available Add-Ons → Add. Select the matching APX, confirm, restart Archicad and verify it loaded. Save a test project and keep it active.

02 / Install the connector

Extract the ZIP and install Python

Download the Windows ZIP. Extract its archicad-connector folder into C:\tools. Install Python 3.12 and uv, then run in PowerShell:

cd C:\tools\archicad-connector
uv sync --frozen --no-dev --python 3.12
.\.venv\Scripts\archicad-connector.exe --version
.\.venv\Scripts\archicad-connector.exe diagnose

The bundle also includes scripts\setup.ps1 for the same locked setup. A pip alternative is documented in its README. No execution-policy change is required for the commands above.

03 / Register with Codex

Point the client to the local executable

With Codex CLI installed, run:

codex mcp add archicad -- C:\tools\archicad-connector\.venv\Scripts\archicad-connector.exe --ports 19723-19743 --timeout 30 serve
codex mcp list

Alternatively, append the following to %USERPROFILE%\.codex\config.toml. Replace the path if you extracted elsewhere.

[mcp_servers.archicad]
command = 'C:\tools\archicad-connector\.venv\Scripts\archicad-connector.exe'
args = ['--ports', '19723-19743', '--timeout', '30', 'serve']
startup_timeout_sec = 30
tool_timeout_sec = 120

Reload Codex. Other local MCP clients can launch the same executable and arguments through their stdio settings. The connector requires no OpenAI API key.

04 / Inspect before writing

Choose the instance and project

  1. Run discover_instances, then connect_instance with an explicit returned port.
  2. Inspect the project, version and project_token. Keep the selected saved project active.
  3. Read the selection and query a Wall before trying a write.
  4. Use the wall/slab examples and the complete live checklist in the ZIP. Mutations require explicit instance_id and project_token.

If a write times out, inspect Archicad before acknowledging the hold. The operation may have succeeded; do not retry blindly.

Full troubleshooting, units, schemas, compatibility and acceptance steps are included in docs/ in the bundle and on GitHub.
