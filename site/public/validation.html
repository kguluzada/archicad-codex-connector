What the tests exercise

Exact Graphisoft and Tapir request envelopes, nested schema constraints, property value states, multiple instances, native errors and partial results, project changes, unsupported versions, serialization and uncertain write recovery.

The stdio workflow discovers tools, connects, inspects the project, creates mock wall and slab records, queries their GUIDs and edits a typed property. These mock records do not prove native object placement, editing or Undo.

Live acceptance still required

  • Windows setup, native Tapir loading and actual Codex GUI registration.
  • Native wall/slab geometry, units, story placement and property editability.
  • Undo/Redo, real Teamwork restrictions, modal dialogs and host timeouts.
  • Individual Archicad major versions and localized installations.

The release includes a step-by-step live checklist. Tapir’s released AC25–30 assets establish distribution coverage, not certification.

Project targeting has a known limit

The connector observes a project fingerprint; the backend does not expose a guaranteed unique native session identity. A close/reopen of the same saved path or a UI switch after the last check can escape detection. Keep the intended project active. There is no automatic rollback, write retry, exactly-once guarantee or verified cancellation.
