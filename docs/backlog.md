# Prioritized remaining work

1. **Run the Windows native acceptance checklist on one chosen Archicad major/build.** Verify actual editable Wall/Slab objects, property read-back, story/reference-plane placement, Undo behavior, Teamwork errors, modal timeouts and the real Codex GUI connection. Then expand the live matrix one major at a time.
2. **Close the native targeting gap.** Evaluate a native session identifier and a host-side expected-project precondition in the same execution context as mutations. Only add a C++ extension if Tapir cannot supply that capability. The present name/path fingerprint cannot certify same-document session identity.
3. **Persist uncertain-operation metadata and recovery holds.** Maintain bounded durable status through connector restarts; inspect uncertain native outcomes before introducing any idempotency/retry mechanism. Native request identifiers would be needed for stronger duplicate detection.
4. **Bound/paginate large-model reads.** Native batched query/detail/property calls, response limits and cursors with measured UI latency on representative models; retain native IDs and avoid hiding partial failures.
5. **Expand the curated native catalogue after live demand.** Include more attribute/property/classification editing or geometry types with exact release schemas, effect labels and native verification. No unrestricted code execution as a substitute for typed coverage.
6. **Distribution/coexistence validation.** Windows CI, non-English paths, co-installed add-ins, signed distribution if needed, upgrade/uninstall and explicit compatibility records. Optional native events need ordering/recovery guarantees before advertising synchronization.

A multi-application broker, geometry exchange platform, custom C++ implementation of existing Tapir commands, remote access service and arbitrary code execution were deliberately omitted from the first release.
