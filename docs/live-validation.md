# Exact Windows live acceptance checklist

**Current status: no live Archicad acceptance run recorded.** Do this on a disposable saved project with a backup. Keep the selected project active during requests. Record Windows build, Python version, Archicad edition/major/build/language, Tapir asset/version, connector version, Codex version and every operation ID/native GUID. Attach native screenshots and structured results to a new validation record; do not overwrite this unverified status with mock results.

1. Install from `uv.lock` using `scripts/setup.ps1`. Confirm `archicad-connector --version` returns `0.1.0`; run `diagnose` and save its JSON output. Confirm Tapir 1.7.0 is loaded in Add-On Manager and the saved project path is correct.
2. Configure the absolute Windows executable from `examples/codex-config.toml`. Reload Codex, verify 15 tools, run `discover_instances`. Start a second Archicad project/instance, rerun and verify both ports appear and no instance is auto-selected. Connect explicitly to the intended port; retain its instance ID/token.
3. Run `inspect_project` and `inspect_selection`. Select two known native elements in Archicad; verify returned GUIDs correspond to the selected elements. Retrieve `tapir.GetStories`; record index/elevation values. Query `Wall` with and without `IsEditable` filters and inspect native details, classifications, layers and building materials.
4. In the saved disposable project create one wall with `create_walls`, using XY `(0,0)→(5,0)`, height `3`, thickness `0.2`, an actual story index, and `zCoordinate=0`. Record the returned GUID. Query walls, read that GUID's details and verify it is an editable **native Wall** with those dimensions and expected story elevation, in plan/3D/Element Settings.
5. Create one slab with four XY corners `(0,0),(5,0),(5,4),(0,4)`, thickness `0.25`, the same actual story index, and `level` set to that story's **absolute elevation**. Verify a native Slab, outline, reference-plane elevation and thickness. Test the native schema's open/closed vertex form, holes/arcs only in a separate recorded case.
6. Resolve a known writable string property with `official.GetPropertyIds`; inspect `official.GetDetailsOfProperties`. Update it on the two returned GUIDs with `{"type":"string","status":"normal","value":"MCP validation"}`. Read back using `read_elements(detail="properties")` with the property ID and verify in native Property Settings. Separately test empty string and `userUndefined` (value absent) on a suitable property.
7. Undo the native creation and property steps in Archicad, one at a time, and verify actual grouping/object/value restoration; redo and verify. Record differences from the source's expected Undo entry. Do not call the batch atomic because an Undo entry exists.
8. Create a two-item batch containing one valid wall and one native-invalid item (for example an invalid story/favorite), and verify successful GUIDs remain visible when the other fails. Record per-item errors and actual native Undo behavior.
9. Pass a stale token after switching saved projects; verify the connector refuses the write before any object appears. Attempt a write to an untitled project; verify refusal. A same-path reopen or switch **between** final check and dispatch is a documented identity gap, not a passed guarantee.
10. On a Teamwork test project, try an unreserved/locked element/property; capture native error codes and verify no bypass. Reserve normally in Archicad and repeat. Record language/localized property names and permissions.
11. Use a short connector HTTP timeout against a deliberately busy host/modal state. Send **one** creation request only. If it returns `outcome_unknown`, check native objects/history; verify subsequent mutations are held, reads are still usable, and the original request is never resent automatically. Acknowledge by operation ID only after inspection. Record what happens after host/server restart; the journal/hold is not persistent.
12. Stop Archicad and run reads/status/diagnostics; verify actionable unavailable errors. Reload with wrong/missing Tapir then confirm clear capability/version errors. Check stdout during `serve` contains only MCP messages and stderr has no complete model payloads.
13. Optional reviewed archive capability: use an absolute new `.pla` path in a disposable directory, verify file contents and Save-As project change; verify an existing destination is refused. Refresh targeting afterward.
14. Repeat essential creation/property/undo cases separately for every Archicad major to be claimed supported. Record co-installed add-ins, non-English Windows paths, large-model response behavior and multiple clients before wider distribution.

Acceptance requires native-object and native-value verification plus a real Windows Codex connection. A ready wheel, 15 discovered tools, schema validation or mock HTTP response alone cannot establish those results.
