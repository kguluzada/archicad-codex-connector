## Primary specifications

- [Graphisoft JSON documentation](https://archicadapi.graphisoft.com/JSONInterfaceDocumentation/index.html) identified **30.0.0.3000** during this inspection. The dynamic documentation loads individual contracts from `content/API.<command>.json` and common type definitions. Reviewed command format, localhost POST/port range, SI units, official query/selection/property/classification schemas and examples. Official adapter input contracts are independently authored, without copying vendor implementation code or redistributing unlicensed documentation bundles.
- [Graphisoft introduction/units/ports](https://archicadapi.graphisoft.com/JSONInterfaceDocumentation/content/introduction.html) and [command format](https://archicadapi.graphisoft.com/JSONInterfaceDocumentation/content/command_format.html).
- [Official typed property read](https://archicadapi.graphisoft.com/JSONInterfaceDocumentation/content/API.GetPropertyValuesOfElements.json), [write](https://archicadapi.graphisoft.com/JSONInterfaceDocumentation/content/API.SetPropertyValuesOfElements.json), [property details](https://archicadapi.graphisoft.com/JSONInterfaceDocumentation/content/API.GetDetailsOfProperties.json), [property type/status forms](https://archicadapi.graphisoft.com/JSONInterfaceDocumentation/content/APIPropertyTypes.json).
- [Official selection](https://archicadapi.graphisoft.com/JSONInterfaceDocumentation/content/API.GetSelectedElements.json), [element query](https://archicadapi.graphisoft.com/JSONInterfaceDocumentation/content/API.GetElementsByType.json), [classification read](https://archicadapi.graphisoft.com/JSONInterfaceDocumentation/content/API.GetClassificationsOfElements.json).
- [C++ AddOnCommand execution policy](https://archicadapi.graphisoft.com/documentation/api_addoncommandexecutionpolicy): native commands can schedule on the main thread. Tapir's inspected `CommandBase::GetExecutionPolicy` selects that route. Graphisoft DevKit/binary licensing remains separate from this MIT Python connector; no DevKit is redistributed.
- [MCP transport specification, 2026-07-28](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports). The released SDK differentiates handshake revisions from modern per-request revisions. The tested local stdio initialization negotiates **2025-11-25**; don't label that handshake 2026-07-28 just because the latest specification has that date.
- [Official Codex MCP configuration](https://learn.chatgpt.com/docs/extend/mcp): checked stdio command/args, TOML namespace and timeout fields. The former developers.openai.com/codex/mcp URL redirects to this official page.
- [Tapir release API](https://api.github.com/repos/ENZYME-APD/tapir-archicad-automation/releases/tags/1.7.0): matching AC25–30 Windows/Mac assets, release published 2026-10-04. A compact asset manifest is saved here; native binaries were not executed.

## Schema provenance and refresh

`src/archicad_connector/data/tapir.json` records the release tag's commit and SHA-256 of each fetched JS definition file. `scripts/vendor_tapir.py` uses pinned HTTPS URLs, parses the assignment's JSON without JS execution, asserts the reviewed allowlist and rewrites only local reference paths to standard `#/definitions/...`. It preserves union structure, descriptions and constraints. Runtime schema lookup includes only reachable definitions; schema validation stays local and never fetches schema references from the network.

Run the vendoring script deliberately when verifying the same pin. Changing the pin/allowlist requires source review, effect classification, tests, notices and compatibility updates together. Official input schemas use the native wire contract, not Python binding coercions; Tapir and official property-value formats must not be interchanged.

## Notices and dependency licensing

- The connector source uses MIT (`LICENSE`). Copied Tapir schema material remains copyright its original authors under MIT; the complete original license is `src/archicad_connector/data/TAPIR_LICENSE.txt` and included in the wheel/sdist.
- The two wrapper repositories declare MIT; because no source/schema material from those wrappers is redistributed here, no wrapper notice is added to connector runtime code.
- Direct runtime dependencies: MCP MIT, HTTPX BSD-3-Clause, JSON Schema MIT, Pydantic MIT. They are installed as separate distributions with their own notices. `uv.lock` pins resolved versions/platform markers and artifact hashes; it is not a full legal/security audit of all transitive packages.
- Archicad and native Tapir binaries are installed by the user, outside this package. A licensed Archicad installation is required; compatible binary load and Graphisoft SDK licensing cannot be established by a Python test.
